Interfaces: alcance y UX inclusiva

Lo que exige el ETS: un prototipo de interfaz de entrada y uno de salida, con fuentes grandes, alto contraste y una descripción debajo de cada imagen. Las demás interfaces se listan para mostrar el alcance, pero no se deben desarrollar todas.
