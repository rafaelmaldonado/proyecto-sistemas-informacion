# Recursos para análisis y evaluación de sistemas de información

## Knowledge

- [NIST — Requirements Verification Tools](https://www.nist.gov/itl/csd/secure-systems-and-applications/requirements-verification-tools)
  Criterios para revisar requisitos: completitud, consistencia, trazabilidad, ausencia de ambigüedad y verificabilidad. Úselo para evaluar requisitos y pruebas.
- [The Scrum Guide (2020)](https://scrumguides.org/scrum-guide.html)
  Definición oficial de Scrum y de sus compromisos; útil para distinguir un backlog de una simple lista de pendientes.
- [Oracle — About Normalization](https://docs.oracle.com/database/121/DWHSG/ch2logdes.htm)
  Explica 1FN, 2FN y 3FN como proceso para almacenar cada hecho una sola vez y evitar anomalías.

## Wisdom (Communities)

- No se requiere comunidad externa para esta evaluación escolar. La revisión docente y la evidencia del estudiante son la fuente de retroalimentación del contexto.
