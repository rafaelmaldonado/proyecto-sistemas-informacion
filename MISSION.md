# Mission: Evaluar un proyecto de Sistemas de Información

## Why
Construir un criterio claro, reproducible y pedagógico para contrastar la entrega de un alumno con la evidencia que debería producir un proyecto de sistema de información para el Centro de Transferencia Canina (CTC).

## Success looks like
- Distinguir los requisitos textuales del documento de las inferencias técnicas necesarias para una entrega completa.
- Revisar documentos, diagramas, tablas, backlog y modelo de datos con una rúbrica trazable.
- Explicar cómo se deriva cada artefacto esperado, no solo marcarlo como presente o ausente.

## Constraints
- El enunciado oficial (Carpeta ETS Agosto 2026-2) contiene los 5 bloques y sus 11 puntos; las lecciones 1–7 cubren los cinco.
- Las lecciones no incluyen quizzes; usan recorridos guiados y listas de verificación.

## Out of scope
- Calificar con una ponderación oficial no proporcionada por el docente.
- Suponer requisitos de bloques no adjuntos como si fueran parte del enunciado.
