Código de ejemplo ejecutable

Prototipo conectado a SQLite

El formulario registra perros y el listado consulta la misma base de datos. Es la implementación mínima necesaria para demostrar interfaz, código y persistencia.

Adáptalo; no lo presentes como autoría propia. Cambia los datos y decisiones según tu organización. En la defensa debes demostrar el recorrido sin leer el código.

1. Instalar Node.js

  1. Entra a nodejs.org/en/download y descarga Node 24 LTS. En Windows usa el instalador .msi; en macOS, el instalador .pkg; en Linux, selecciona tu sistema y sigue el comando mostrado por la página oficial.
  2. Ejecuta el instalador, conserva las opciones predeterminadas y vuelve a abrir la terminal al finalizar.
  3. Comprueba la instalación:
    node --version
    Debe mostrar v24.... También funciona desde Node 22.5, versión en la que se incorporó node:sqlite.
No ejecutes npm install: este prototipo no usa paquetes externos; node:http y node:sqlite vienen con Node.

2. Abrir el proyecto en la terminal

cd significa “cambiar de carpeta”. Sustituye la ruta del ejemplo por la carpeta donde guardaste el proyecto:

cd ruta/al/proyecto-sistemas-informacion

Comprueba que estás en la carpeta correcta:

node --version
ls code

En Windows PowerShell puedes usar dir code en lugar de ls code. Debe aparecer server.js.

3. Iniciar la aplicación

node code/server.js

Este comando pide a Node ejecutar server.js. Si todo está bien, muestra Prototipo disponible en http://localhost:8000. Mantén esa terminal abierta y visita http://localhost:8000 en el navegador.

No abras los HTML con doble clic: la interfaz podría verse, pero no podría registrar ni consultar porque necesita que server.js atienda las rutas /api/perros.

Para detener la aplicación, vuelve a la terminal y presiona Ctrl + C. El archivo code/database/centro-adopcion.db conserva los registros.

4. Ejecutar las pruebas

Detén el servidor con Ctrl + C o abre una segunda terminal en la misma carpeta. Después ejecuta cada prueba por separado:

node code/tests/database.test.js
node code/tests/validaciones.test.js
node code/tests/backup.test.js

Cada comando debe imprimir un mensaje que empiece con OK. Comprueban la BD, las reglas CP-01..CP-04 y el respaldo cifrado.

5. Crear y restaurar un respaldo cifrado

Primero inicia la aplicación al menos una vez para crear la BD. Después detenla y ejecuta en macOS o Linux:

BACKUP_PASSWORD='una-clave-larga-y-privada' node code/backup.js crear
BACKUP_PASSWORD='una-clave-larga-y-privada' node code/backup.js restaurar

En Windows PowerShell:

$env:BACKUP_PASSWORD='una-clave-larga-y-privada'
node code/backup.js crear
node code/backup.js restaurar
Remove-Item Env:BACKUP_PASSWORD

crear produce un archivo .enc; restaurar crea una BD separada y no sobrescribe la base activa. No publiques la contraseña, la BD ni su respaldo.

6. Consultar SQLite directamente (opcional)

Este comando requiere tener la herramienta sqlite3 instalada; no es necesario para usar la aplicación:

sqlite3 code/database/centro-adopcion.db "SELECT id_perro,nombre,estado FROM perro;"
Defensa y proceso: sigue la validación de conocimiento antes de tomar capturas.
